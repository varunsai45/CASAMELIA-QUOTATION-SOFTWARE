# Bundled cloud PDF fonts

DejaVu Sans regular and bold 2.37 are included for Linux/serverless hosts that
have no system fonts. Calibri remains the first choice on existing Windows
installations. Existing saved documents are served unchanged.

Source: https://github.com/dejavu-fonts/dejavu-fonts/releases/tag/version_2_37
